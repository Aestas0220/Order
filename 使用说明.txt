来点 · 云端点单系统
入口：https://aestas0220.github.io/Order/
后台：Cloudflare Workers + D1

在收银台、制作清单或副屏输入同一个固定密码即可使用，不再需要二维码配对，也不要求同一 Wi-Fi。笔记本同一个浏览器的副屏会沿用收银台登录状态。

订单和号码保存在 Cloudflare 数据库中。平板锁屏时不会继续实时更新；解锁回到网页会自动重新获取订单。网页每 5 秒更新，网络中断时暂停操作，恢复网络后自动继续。同一订单的重复提交沿用原号码；并发订单通过数据库统一发号，出餐有版本检查。

固定密码由本人在 Cloudflare Worker 的 Settings → Runtime variables and secrets 设置，类型 Secret，变量名称 ACCESS_PASSWORD，至少 8 位。密码不会出现在 GitHub 代码中。登录状态保留 7 天；修改密码会使旧登录状态失效。

先核实现金或微信、支付宝实际到账，再创建订单并手写号码。制作台上栏为制作中，下栏为请取餐。副屏使用全屏群峦毛玻璃设计。可改价、上下架、导出订单 CSV。

云端使用独立订单库，开始号码为 001。旧二维码版的浏览器记录仍留在原浏览器，不会自动导入；不要在同一营业场次混用新旧版本。营业前核对菜单价格，并在学校网络上试单。
