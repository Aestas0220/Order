# 来点 · GitHub Pages 点单系统

入口：https://aestas0220.github.io/Order/

笔记本同一浏览器打开收银台与副屏。平板连接同一热点，打开制作清单，通过收银台「现场设置 → 平板配对」交换配对码与回传码。

先确认微信、支付宝或现金到账，再提交发号，手写号码给顾客。制作台确认整单出餐后，副屏更新；支持撤回。可改价、上下架、导出 CSV。

订单保存在收银笔记本浏览器的 IndexedDB 中，平板通过 WebRTC 直接连接。不需要 Python 或外部数据库。请保持收银窗口打开，不使用无痕模式，不清理网站数据，不在同一次营业中更换收银设备、浏览器或浏览器配置文件，否则会创建独立号码序列。刷新保留订单，但平板需重新配对。

此版本适用于同一热点或同一 Wi-Fi；不同移动网络不能保证连接。真实平板尚需现场试单，热点隔离、防火墙、浏览器可能影响配对。未建立连接时制作设备不能更改订单。

网站首次开启：Settings → Pages → main → / (root) → Save。
