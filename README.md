# 来点 · GitHub Pages 点单系统

入口：https://aestas0220.github.io/Order/

- 笔记本同一浏览器打开收银台、副屏两个窗口。
- 平板和笔记本连接同一 Wi-Fi 或笔记本热点，再打开制作清单。
- 收银台的「现场设置 → 平板配对」生成配对码，通过微信发送到平板。平板生成回传码，发给收银台粘贴，完成连接。
- 先确认微信、支付宝或现金到账，再点「确认已收款 · 提交发号」，把号码写给顾客。
- 制作台整单做好后确认出餐，副屏自动更新。支持撤回。

## 必须了解

GitHub Pages 只托管静态网页。此版本不依赖外部数据库，订单保存在收银笔记本的 IndexedDB 中，平板通过 WebRTC 直接连接笔记本。请保持收银窗口打开，不使用无痕模式，不清理网站数据，不切换收银浏览器或电脑。刷新后号码延续；清空浏览器数据或换设备将产生独立号码，请勿在同一次营业中这样操作。

副屏只支持收银笔记本的同一个浏览器。平板配对仅支持同一网络；独立移动网络无法保证连接。浏览器刷新或断线后平板需要重新配对。浏览器、热点隔离或防火墙可能阻止直连，营业前一定用真实平板试单。

收银台可改价、上下架，导出 CSV。雪糕中间档默认关闭，营业前核对价格。没有上传支付截图或自动核实支付的功能。

## 发布

Settings → Pages → Deploy from a branch → main → / (root) → Save。
